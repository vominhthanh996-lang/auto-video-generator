# Create Video QA Project

Trang này là project video mới để bạn hỏi, thử brief, chốt storyboard, rồi render riêng mà không đụng job đang chạy.

- Format mặc định: 9:16 vertical
- Ngôn ngữ mặc định: tiếng Việt
- Voice mặc định: vi-female
- Trạng thái: chờ brief/nội dung từ bạn

Gửi tiếp ý tưởng, script, hoặc yêu cầu chỉnh style; mình sẽ cập nhật storyboard trong project này.
